# ระบบจำลองการคัดแยกขยะ Trash Sorting

โปรแกรมจำลองการคัดแยกขยะด้วย Python บน Processing โดยแก้ปัญหาการทิ้งขยะปะปนกันจนขยะรีไซเคิลเสียมูลค่า ตัวโปรแกรมรับค่าจำนวนขยะ บันทึกลงไฟล์ .txt แล้วดึงกลับมาจำลองการทิ้งลงถัง 3 ประเภท

---

### การทำงานของโค้ด

การใช้ OOP และ Polymorphism แทนที่จะเขียน if-else เช็กชื่อขยะทีละชิ้น โปรแกรมนี้สร้างคลาสแม่ชื่อ Trash ไว้คุมเรื่องพิกัดและการเคลื่อนที่ แล้วแตกคลาสลูกออกมา 3 ตัวคือ RecyclableTrash, OrganicTrash, และ GeneralTrash คลาสลูกแต่ละตัวจะมีเมธอดชื่อเดียวกัน แต่คืนค่าต่างกันตามประเภทของตัวเอง ตอนโปรแกรมทำงานก็แค่สั่งเรียกเมธอดเหล่านี้ ขยะแต่ละชิ้นก็จะรู้เองว่าต้องวิ่งไปถังไหน ใช้สีอะไร และหนักเท่าไหร่

การจัดการข้อมูลใช้ Dictionary ที่ชื่อ CATEGORY จับคู่ชื่อขยะกับคลาสไว้ด้วยกัน พออ่านข้อความจากไฟล์ปุ๊บ ก็ดึงคลาสออกมาสร้างอ็อบเจกต์ได้ทันที ส่วนการเคลื่อนไหวบนหน้าจอจะใช้ List สองตัวช่วยกันทำงานคือ spawn_queue เอาไว้เข้าคิวรอปล่อยขยะทีละชิ้นไม่ให้ทับกัน และ active_trash เอาไว้เก็บขยะเพื่ออัปเดตตำแหน่งจนกว่าจะลงถัง

โมดูลและการจัดการไฟล์ ใช้ Counter มาช่วยนับยอดขยะในแต่ละถังแบบไม่ต้องเขียนลูปบวกเลขเอง ส่วนการเซฟและโหลดข้อมูลใช้คำสั่ง open("trash.txt") เพื่อเขียนรายการขยะลงไฟล์ตอนกด SAVE และอ่านกลับมาทีละบรรทัดตอนกดเริ่มจำลอง

ฟังก์ชันหลักในโปรแกรมพึ่งพาลูปของ Processing คือ setup() ที่ตั้งค่าหน้าต่างตอนเริ่ม และ draw() ที่คอยวาดหน้าจอใหม่ รวมถึงขยับก้อนขยะให้ตกลงมา ส่วนการทำงานตามปุ่มกดจะถูกแยกไปอยู่ใน mousePressed() ซึ่งคอยเช็กพิกัดเมาส์แล้วเรียกใช้ฟังก์ชัน save_to_file() เพื่อเขียนไฟล์ หรือ start_simulation() เพื่ออ่านไฟล์และเริ่มปล่อยขยะอีกที

---

### วิธีใช้งาน

เปิดโปรแกรม **Processing** เปลี่ยนโหมดเป็น **Python** และใช้โค้ดจาก a2.pyde

1. กดปุ่ม +/- ทางซ้ายมือเพื่อกำหนดจำนวนขยะแต่ละชนิดตามต้องการ
2. กดปุ่ม SAVE โปรแกรมจะเขียนรายการขยะทั้งหมดลงไฟล์
3. กดปุ่ม START โปรแกรมจะอ่านไฟล์แล้วปล่อยก้อนขยะไหลลงถังตามประเภท พร้อมนับจำนวนและคำนวณน้ำหนักรวมด้านบน
4. กดปุ่ม RESET ถ้าต้องการเคลียร์ตัวเลขในถังทั้งหมดกลับเป็นศูนย์
